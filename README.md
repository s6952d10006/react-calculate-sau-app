# React Calculate SAU App

เครื่องมือคำนวณ BMI, BMR และเงินผ่อนรถ พัฒนาด้วย React, Vite และ Tailwind CSS
จัดทำเฉพาะ UI ตามต้นแบบอาจารย์ และคงโครงสร้าง `src/pages`, `src/components`, `src/assets` เดิม

## เปิดโปรเจกต์

เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรัน:

```powershell
npm.cmd ci
npm.cmd run dev
```

เปิด http://localhost:3377 และกด `Ctrl+C` ใน Terminal เพื่อหยุด
บน macOS/Linux ใช้ `npm` แทน `npm.cmd`

## หน้าจอ UI

- `/` เมนูหลัก ใช้ `CardMenu` รับ props รูป ชื่อ รายละเอียด และ `routePath`
- `/bmi` ฟอร์มน้ำหนักและส่วนสูง พร้อมปุ่มและพื้นที่แสดงผลตัวอย่าง
- `/bmr` ฟอร์มน้ำหนัก ส่วนสูง อายุ และตัวเลือกเพศ
- `/car` ฟอร์มชื่อผู้ซื้อ ราคารถ ดอกเบี้ย เงินดาวน์ และระยะเวลาผ่อน
  เลือกได้ 24, 36, 48, 60, 72 หรือ 84 เดือน

งานรอบนี้เป็น UI เท่านั้น: กรอกข้อมูลและเลือกตัวเลือกได้ แต่ปุ่มคำนวณและรีเซ็ต
ยังไม่มีโพรเซสการทำงาน ผลลัพธ์แสดงตัวอย่าง `0.00` คงที่
ลิงก์เมนูและลิงก์กลับหน้าหลักใช้งานได้ตามปกติ

## ตรวจสอบโค้ด

```powershell
npm.cmd run lint
npm.cmd run build
```

คงชื่อโฟลเดอร์ `pages` ตามความต้องการของเจ้าของโปรเจกต์
ซึ่งต่างจากชื่อ `views` ที่ระบุในภาพโจทย์
